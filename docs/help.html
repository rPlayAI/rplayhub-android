rPlayHub Android Help

Mirror and control your Android phone from the Mac — screen, touch, audio and clipboard — with a gyroscope-tracked 3D twin and app windows on virtual displays. Nothing is installed on the phone: a small agent runs over adb for the session and leaves with it.

Getting started

  1. Enable debugging on the phone. Settings ▸ System ▸ Developer options ▸ turn on USB debugging (and Wireless debugging for cable-free use). If Developer options is hidden, tap Settings ▸ About phone ▸ Build number seven times.
  2. Connect. Plug in a USB cable, or pair once over Wi-Fi (adb pair with the code shown under Wireless debugging, then adb connect <phone-ip>:5555). The device appears in the sidebar.
  3. Select the device. The session is prepared in the background the moment a ready device is selected, so the mirror opens instantly when you ask for it.
  4. View Screen. Click the View Screen button (or Device ▸ Start Screen Mirroring, ⌘M) and the live picture appears.
Note

The first device may show an Allow USB debugging? prompt on the phone — accept it (check “Always allow from this computer” to skip it next time).

The window

Three panes, like Device Hub on iPhone:

Devices (left)
Every phone adb can see, with its state. Right-click a device for Start/Stop Screen Mirroring, Copy Serial, Disconnect.
Stage (middle)
The live mirror in a real device bezel — or the 3D twin when that mode is on. The control strip underneath holds Back / Home / Recents, volume, power, rotate, screenshot and screen recording.
Inspector (right)
Info (device properties and live stream health), Apps (launch, force-stop, install, export), and Files.

View ▸ Open Screen in New Window (⌘N) pops the stage into its own window — handy for recording a clean demo.

Screen mirroring

  • Touch: click taps, drag swipes and scrolls, and flings and long-presses behave like a finger — the phone’s own gesture recognition does the interpreting.
  • Type on the Mac keyboard and it lands on the phone.
  • Scroll with the trackpad or wheel anywhere on the picture.
  • Drag & drop: drop an .apk to install it; drop any other file and it lands in the phone’s Download folder.
  • Clipboard syncs both ways while mirroring.
  • Audio from the phone plays through the Mac (Android 12+).
  • Screenshot and screen recording buttons save what the phone shows.

Rotation

The mirror follows the phone: rotate the phone (with auto-rotate on) and the picture and bezel follow. The toolbar’s Rotate button instead forces the next orientation — the agent locks the phone’s auto-rotate while a forced orientation is active. Device ▸ Follow Device Rotation hands control back to the phone’s sensor and restores the auto-rotate setting (ending the session restores it too).

Tip

The Android home screen itself doesn’t rotate unless the launcher’s “Allow Home screen rotation” setting is on — apps rotate regardless.

Device features

Turn Screen Off While Mirroring
Blanks the phone’s panel while the mirror stays live — scrcpy’s classic privacy/battery trick. The panel is restored when the session ends.
Synchronize Clipboard
Two-way clipboard sync toggle.
Forward Audio
Phone audio through the Mac’s output.
Pause Display
Freezes the stream without ending the session.
Mirror Display
Pick which of the phone’s displays to mirror when it has more than one.
Follow Device Rotation
Returns orientation control to the phone after the Rotate button froze it.
Show Files in Finder
The phone’s storage as a location in Finder (⇧⌘E, or the device’s right-click menu). Drag photos and files out of it, drop files into it, rename, delete, make folders — it is the phone’s shared storage, live, for as long as the device is connected. The first time, macOS asks you to switch the extension on: System Settings › General › Login Items & Extensions › File Providers › rPlayHub Android.

Virtual displays experimental

Device ▸ Desktop Mode (⌘D) is the one-click version: a 1920×1080 display opens in its own window showing Android’s desktop shell — wallpaper, taskbar, launcher — and whatever you start there runs beside the phone’s own screen. Or pick any app directly: right-click it in the Apps tab ▸ Open on Virtual Display, and it opens in a clean window titled with the app’s name.

Device ▸ New Virtual Display creates the display without the window treatment — phone, tablet or desktop sized — like scrcpy’s --new-display. Click and type in the viewer to drive any of them. Closing the app window (or Device ▸ Close Virtual Display) tears the display down and returns to the phone’s screen. The phone is kept awake automatically while a virtual display exists.

Limitations

The feature is experimental. The virtual display shares the phone’s power state, so the phone’s screen must stay awake for apps on the virtual display to run; some apps decline to move displays while already running.

3D Device Twin

The signature trick: a 3D model of the phone in the stage, showing the live mirror on its screen and tracking the real phone’s orientation from its gyroscope. Turn the phone in your hand and the model turns with it.

  • Enable the mode from the View menu, with a live session running.
  • Hold the phone facing you and press Set Facing Me (R) once — that pose becomes “facing you” and is remembered for later sessions.
  • The twin’s screen is touchable: click it to tap the phone, drag to scroll.
  • Drag empty space to orbit the camera; scroll to dolly.
  • View ▸ Set 3D Back Image… skins the model’s back with your own picture; without one, a procedural Pixel-style back (camera bar and G) is drawn.
  • View ▸ Show 3D Demo plays a scripted rotation reel — nice for videos.

Inspector panels

Info
Device identity (model, Android version, ABI, build) and live stream counters — packets, decoded/shown frames, resolution, rotation, bitrate, gyro and audio flow.
Apps
Everything installed. Double-click or right-click to Launch (onto the mirrored display), Force Stop, Copy Package Name, Export APK… to the Mac, or Uninstall. Install APK… installs from the Mac.
Files
Browse the phone’s storage and pull files to the Mac.

Troubleshooting

The phone’s Finder location never loads

macOS keeps a new Finder location switched off until you allow it. Open System Settings › General › Login Items & Extensions, scroll to Extensions › File Providers, and turn on rPlayHub Android. The location also only works while the app is running with the device connected.

The device shows “unauthorized”

Unlock the phone and accept the Allow USB debugging? prompt, then select the device again.

The device shows “offline”

Reseat the cable, or for Wi-Fi devices reconnect with adb connect <phone-ip>:5555. Toggling Wireless debugging off and on resets a stale connection.

The picture stutters or the session drops over Wi-Fi

The stream competes for airtime with everything else on the network. Moving closer to the router, using 5 GHz, or plugging in USB gives the smoothest picture. A dropped session reconnects automatically.

The phone’s auto-rotate tile turned itself off

The toolbar’s Rotate button did that — a forced orientation requires it. Device ▸ Follow Device Rotation restores it, and so does ending the session.

The mirror doesn’t rotate on the home screen

That’s the launcher: most Android home screens stay portrait unless “Allow Home screen rotation” is enabled in the launcher’s settings. Open any app that rotates and the mirror follows it.
